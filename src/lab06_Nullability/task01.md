# Практичне завдання: Null Safety та обробка Nullable-типів у Kotlin

**Тема:** Система типів Kotlin, Nullable-типи (`T?`), оператор безпечного виклику (`?.`), Elvis-оператор (`?:`), безпечне приведення типів (`as?`), оператор небезпечного розпакування (`!!`), фільтрація колекцій (`filterNotNull`) та Smart Casts.

---

### Мета роботи
Опанувати ідіоматичні підходи Kotlin для запобігання помилкам `NullPointerException` (NPE):
1. Робота з опціональними та вкладеними структурами даних.
2. Задання значень за замовчуванням та переривання виконання за допомогою Elvis-оператора.
3. Безпечне приведення типів без ризику `ClassCastException`.
4. Очищення та обробка колекцій із потенційними `null`-значеннями.

---

## 1. Вхідні дані та моделі

Створіть файл `NullSafetyTasks.kt` та додайте до нього структуру даних інтернет-магазину:

```kotlin
data class Address(
    val street: String,
    val city: String?,
    val postalCode: String?
)

data class Client(
    val id: Int,
    val name: String,
    val email: String?,
    val address: Address?,
    val extraData: Any? // Може містити рядок, число або null
)

val clientList = listOf(
    Client(
        id = 1,
        name = "Олена",
        email = "olena@example.com",
        address = Address("вул. Саксаганського, 10", "Київ", "01033"),
        extraData = "VIP-клієнт"
    ),
    Client(
        id = 2,
        name = "Богдан",
        email = null,
        address = Address("вул. Городоцька, 45", "Львів", null),
        extraData = 42
    ),
    Client(
        id = 3,
        name = "Марія",
        email = "maria@example.com",
        address = null,
        extraData = null
    ),
    Client(
        id = 4,
        name = "Дмитро",
        email = null,
        address = Address("вул. Соборна, 1", null, null),
        extraData = "Очікує дзвінка"
    )
)
```

## 2. Завдання для виконання

### Завдання 1. Ланцюжок безпечних викликів та Elvis-оператор (`?.`, `?:`)
Напишіть функцію:
```kotlin
fun getShippingLabel(client: Client): String
```
**Вимоги:**
* Сформуйте рядок формату доставки для клієнта.
* Отримайте назву міста з поля `client.address?.city`. Якщо адреса відсутня або місто дорівнює `null`, замість назви міста підставте `"Місто не вказано"`.
* Отримайте поштовий індекс (`postalCode`). Якщо індекс відсутній, підставте `"Індекс невідомий"`.
* Якщо сама адреса (`address`) дорівнює `null`, функція повинна повернути рядок:  
  `"Самовивіз: Клієнт <name> не надав адреси"`.
* Перевірте роботу функції для клієнтів **Олена**, **Богдан** та **Марія**.

---

### Завдання 2. Безпечне приведення типів (`as?`) та Smart Cast
Поле `extraData` має тип `Any?` і приходить із зовнішнього джерела.

Напишіть функцію:
```kotlin
fun printClientNote(client: Client)
```
**Вимоги:**
1. Спробуйте привести `client.extraData` до типу `String?` за допомогою оператора безпечного приведення `as?`.
2. За допомогою Elvis-оператора встановіть значення за замовчуванням: `"Додаткові примітки відсутні"`, якщо значення не є рядком або є `null`.
3. Виведіть результат у консоль у вигляді:  
   `"Клієнт ${client.name} -> Примітка: <значення>"`.
4. Перевірте функцію для всіх 4-х клієнтів зі списку (зверніть увагу, що у клієнта Богдана там число `42`).

---

### Завдання 3. Фільтрація списків та збір контактів (`filterNotNull`)
Компанія планує розсилку промокодів через електронну пошту.

1. Отримайте зі списку `clientList` повний перелік email-адрес:
    * Спочатку трансформуйте список клієнтів у список адрес (`List<String?>`).
    * За допомогою методу `filterNotNull()` відкиньте всі `null`-значення, отримавши чистий тип `List<String>`.
2. Знайдіть довжину найкоротшого email серед знайдених за допомогою безпечного виклику довжини рядка.
3. Виведіть сформований список валідних email-адрес та довжину найкоротшого.

---

### Завдання 4. Валідація з викиданням винятку (`?: error(...)` або `requireNotNull`)
Напишіть функцію пошуку обов'язкових даних:
```kotlin
fun getClientEmailOrThrow(client: Client): String
```
**Вимоги:**
* Якщо `client.email` не є `null`, функція повертає його значення (тип `String`).
* Якщо `client.email == null`, функція повинна викинути виняток `IllegalArgumentException` із текстом:  
  `"Клієнт з ID ${client.id} не має електронної пошти!"`.  
  *(Реалізуйте це за допомогою Elvis-оператора `?: throw ...` або стандартної функції `checkNotNull()` / `requireNotNull()`)*.
* У блоці `try-catch` перевірте виклик цієї функції для клієнта з `id = 2` та виведіть повідомлення про перехоплену помилку.

---

### Завдання 5. Дослідження оператора `!!` (Anti-pattern vs свідомий ризик)
1. Створіть функцію, яка намагається напряму отримати поштовий індекс через оператор подвійного оклику:
   ```kotlin
   fun forceGetPostalCode(client: Client): String
   ```
2. Викличте її для клієнта з `id = 1` (успішний випадок).
3. Викличте її для клієнта з `id = 2` всередині блоку `try-catch` та перехопіть `NullPointerException`.
4. У коментарі до коду напишіть **коротке пояснення (1-2 речення)**: у якій єдиній ситуації в реальних проєктах припустимо використовувати оператор `!!`?
