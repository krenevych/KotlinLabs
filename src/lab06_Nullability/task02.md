# Практичне завдання: Ланцюжки Scope-функцій та обробка масивів у Kotlin

**Тема:** Неперервні ланцюжки викликів (*fluent call chain*), Scope-функції (`let`, `apply`, `also`, `run`), обробка Nullable-типів (`?.`) без використання проміжних локальних змінних.

---

### Мета роботи
Навчитися комбінувати scope-функції для виконання послідовності операцій: валідації, модифікації об'єкта "на місці", побічних ефектів (вивід у консоль) та редукції даних до єдиного результату — без оголошення жодної змінної (`val`/`var`) у точці входу `main()`.

---

## Технічні вимоги

### 1. Функція генерації масиву
Створіть функцію `generateRandomArray(size: Int, maxValue: Int): IntArray?`:
* **Вхідні параметри:**
    * `size: Int` — кількість елементів масиву;
    * `maxValue: Int` — верхня межа діапазону випадкових чисел (включно).
* **Логіка роботи:**
    * Якщо `size <= 0` або `maxValue <= 0`, функція повертає **`null`**.
    * В іншому випадку повертає масив типу `IntArray`, заповнений випадковими цілими числами в діапазоні від `0` до `maxValue`.
      *(Підказка: можна використати `java.util.Random` або `kotlin.random.Random.nextInt(0, maxValue + 1)`).*

---

### 2. Побудова ланцюжка в `main()`

> ⚠️ **Суворе обмеження:** У тілі функції `main()` **заборонено** оголошувати будь-які змінні (`val` або `var`). Вся логіка — це єдиний неперервний ланцюжок викликів scope-функцій, що починається безпосередньо з виклику `generateRandomArray(...)`.

**Необхідна послідовність операцій у ланцюжку:**

1. **Безпечний вхід (`?.let`):**
   Викличте `generateRandomArray(size = 10, maxValue = 50)` та організуйте безпечний виклик. Якщо повернуто `null`, подальший ланцюжок не повинен виконуватися. *(Опціонально: додайте Elvis-оператор `?: println("Помилка вхідних даних")` для обробки `null`).*

2. **Модифікація елементів "на місці" (`apply`):**
   Змініть елементи поточного масиву безпосередньо в ньому:
    * Кожен **непарний** елемент збільшіть удвічі (`x * 2`);
    * Кожен **парний** елемент зменшіть удвічі (`x / 2`, цілочисельне ділення).  
      *(Використайте `apply`, оскільки він повертає контекстний об'єкт `this`).*

3. **Логування масиву (`also`):**
   Виведіть модифікований масив у консоль у зручному для читання вигляді (наприклад, через `it.contentToString()`).  
   *(Використайте `also` для виконання побічної дії без зміни об'єкта в ланцюжку).*

4. **Обчислення максимуму (`run` або `let`):**
   Знайдіть максимальний елемент у масиві (`maxOrNull()`), трансформувавши контекстний об'єкт із масиву в одне чисельне значення.
