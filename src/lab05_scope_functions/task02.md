# Практичне завдання: Ланцюжки Scope-функцій та обробка масивів у Kotlin

**Тема:** Побудова неперервних ланцюжків викликів (*fluent call chain*), Scope-функції (`apply`, `also`, `run`, `let`), мутація та агрегація даних без створення проміжних змінних.

---

### Мета роботи
Опанувати свідоме комбінування scope-функцій у вигляді єдиного конвеєра:
1. **`also`** — виконання побічних дій (проміжне логування стану) без розриву ланцюжка.
2. **`apply`** — модифікація об'єкта "на місці" через контекстний об'єкт `this`.
3. **`run`** — агрегація та обчислення метрик над об'єктом із поверненням нового результату.
4. **`let`** — трансформація обчислених даних в інший тип (мапінг у рядок).

> ⚠️ **Головні обмеження:**
> 1. У тілі функції `main()` **заборонено оголошувати змінні** (`val` або `var`). Уся логіка програми має бути одним неперервним виразом.

## 1. Вхідні дані та допоміжні структури

Створіть файл `ArrayChainTasks.kt` та додайте опис моделі для збереження статистики:

```kotlin
data class ArraySummary(
    val maxElement: Int,
    val elementsOverLimit: Int,
    val totalSum: Int
)
```

Опишіть функцію генерації масиву, яка гарантовано повертає ненульовий результат:

```kotlin
fun generateRandomArray(size: Int, maxValue: Int): IntArray {
    require(size > 0 && maxValue > 0) { "Розмір та максимальне значення мають бути більшими за нуль" }
    return IntArray(size) { kotlin.random.Random.nextInt(1, maxValue + 1) }
}
```

## 2. Покроковий сценарій ланцюжка в `main()`

Розпочніть виконання з виклику `generateRandomArray(size = 8, maxValue = 40)` і побудуйте наступний ланцюжок:

### Крок 1. Логування початкового стану (`also`)
* **Контекст:** `it` (посилання на створений `IntArray`).
* **Дія:** Виведіть згенеровані числа у консоль за допомогою `it.contentToString()`.
* **Формат повідомлення:** `Початковий масив: [числа]`

### Крок 2. Модифікація елементів "на місці" (`apply`)
* **Контекст:** `this` (прямий доступ до методів та індексів масиву).
* **Дія:** Переберіть масив за індексами (`indices`) та змініть значення елементів:
    * якщо число **непарне** — помножте його на `2`;
    * якщо число **парне** — розділіть його на `2` (цілочисельне ділення).

### Крок 3. Логування модифікованого стану (`also`)
* **Контекст:** `it` (посилання на той самий, але вже змінений `IntArray`).
* **Дія:** Виведіть оновлений масив у консоль, щоб зафіксувати результати змін.
* **Формат повідомлення:** `Модифікований масив: [числа]`

### Крок 4. Обчислення аналітики та агрегація (`run`)
* **Контекст:** `this` (масив як контекст для виклику аналітичних методів).
* **Дія:** За допомогою стандартних функцій масиву розрахуйте:
    1. `maxElement` — максимальний елемент через `reduce { max, x -> maxOf(max, x) }` *(використовуємо `reduce`, щоб уникнути повернення `null`)*;
    2. `elementsOverLimit` — кількість елементів, строго більших за `20` (`count { ... }`);
    3. `totalSum` — суму всіх елементів масиву (`sum()`).
* **Результат виразу:** Створіть та поверніть екземпляр класу `ArraySummary(...)`.

### Крок 5. Трансформація статистики у звіт (`let`)
* **Контекст:** `it` (об'єкт типу `ArraySummary`).
* **Дія:** Трансформуйте об'єкт статистики у форматований багаторядковий текст (`String`).

### Крок 6. Друк результату (`also`)
* **Контекст:** `it` (сформований рядок).
* **Дія:** Виведіть отриманий звіт у консоль за допомогою `println(it)`.

## 4. Каркас рішення для самоперевірки

```kotlin
fun main() {
    generateRandomArray(size = 8, maxValue = 40)
        .also { /* Крок 1: логування початкового масиву через it */ }
        .apply { /* Крок 2: зміна чисел через this */ }
        .also { /* Крок 3: логування зміненого масиву через it */ }
        .run {
            // Крок 4: розрахунок і повернення ArraySummary через this
            ArraySummary(
                maxElement = reduce { max, x -> maxOf(max, x) },
                elementsOverLimit = count { it > 20 },
                totalSum = sum()
            )
        }
        .let {
            // Крок 5: створення рядка-звіту з об'єкта ArraySummary
            """
            ----------------------------------------
            ЗВІТ ОБРОБКИ МАСИВУ:
             • Найбільше значення: ${it.maxElement}
             • Кількість елементів > 20: ${it.elementsOverLimit}
             • Сумарне значення: ${it.totalSum}
            ----------------------------------------
            """.trimIndent()
        }
        .also { println(it) } // Крок 6: фінальний вивід
}
```
