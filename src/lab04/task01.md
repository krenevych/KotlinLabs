# Практичне завдання: Класи, властивості та конструктори в Kotlin

**Тема:** Первинні та вторинні конструктори, блок `init`, перевірка контрактів через `require()`, кастомні гетери/сетери (`backing field`), обчислювані властивості та робота з виключеннями.

---

### Предметна область
Квадратне рівняння має вигляд:  
$$ax^2 + bx + c = 0$$  
Головна умова існування саме **квадратного** рівняння: $a \neq 0$.  
Кількість дійсних коренів визначається дискримінантом: $D = b^2 - 4ac$.

---

## 📋 Хід виконання роботи

### Частина 1. Конструктори та валідація
1. **Первинний конструктор без властивостей:**  
   Опишіть клас `QuadraticEquation`. Спочатку оголосіть параметри конструктора як звичайні аргументи без `val` або `var`: `(a: Double, b: Double, c: Double)`.
2. **Валідація в `init`:**  
   У блоці `init` перевірте, чи коефіцієнт `a` не дорівнює `0.0`. Якщо умова порушена — згенеруйте `IllegalArgumentException` (скористайтеся ідіоматичною функцією Kotlin `require(a != 0.0) { "Коефіцієнт 'a' не може бути нулем!" }`).
3. **Властивості в первинному конструкторі:**  
   Зробіть рефакторинг: оголосіть коефіцієнти безпосередньо як незмінювані властивості первинного конструктора: `(val a: Double, val b: Double, val c: Double)`. Переконайтеся, що блок `init` продовжує валідувати значення `a`.
4. **Вторинні конструктори (`constructor`):**
    * Додайте вторинний конструктор, який приймає цілочисельні коефіцієнти: `(a: Int, b: Int, c: Int)` і делегує виклик до первинного (`: this(...)`) з явним приведенням типів через `.toDouble()`.
    * Додайте ще один вторинний конструктор для зведеного квадратного рівняння ($a = 1.0$), який приймає лише два коефіцієнти: `(b: Double, c: Double) : this(1.0, b, c)`.

---

### Частина 2. Обчислювані властивості та поведінка
5. **Метод `toString()`:**  
   Перевизначте метод `toString()`, щоб він повертав читабельний вигляд рівняння, наприклад: `"2.0x^2 + (-4.0)x + 2.0 = 0"` або `"x^2 + 5.0x - 6.0 = 0"`.
6. **Обчислювана властивість (Custom Getter):**  
   Опишіть властивість для дискримінанта: `val discriminant: Double`.  
   *Важливо:* реалізуйте її не через збережене поле, а через користувацький гетер `get() = b * b - 4 * a * c`. Поясніть, чому для обчислюваних значень краще використовувати саме `get()`.
7. **Метод розв'язання рівняння `solve()`:**  
   Створіть метод `solve(): List<Double>`, який повертає дійсні корені рівняння:
    * якщо $D > 0$ — список із двох чисел `listOf(x1, x2)`;
    * якщо $D = 0$ — список з одним числом `listOf(x)`;
    * якщо $D < 0$ — порожній список `emptyList()`.

### Частина 3. Мутабельність і Backing Field
8. **Кастомний сетер для `a`:**  
   Змініть модифікатор коефіцієнта `a` з `val` на `var`.  
   Реалізуйте для нього кастомний сетер `set(value)`, який:
    * перевіряє умову `require(value != 0.0)`;
    * присвоює нове значення внутрішньому полю через ключове слово `field`.
9. **Мутабельність `b` та `c`:**  
   Зробіть властивості `b` та `c` змінними (`var`).  
   Змініть коефіцієнти вже створеного об'єкта та переконайтеся, що значення властивості `discriminant` автоматично перераховується на льоту завдяки `get()`.

---

### Частина 4. Практичне застосування та колекції
10. **Масова генерація та фільтрація:**
    * За допомогою `List(100) { ... }` або циклу згенеруйте 100 екземплярів `QuadraticEquation` із випадковими коефіцієнтами в діапазоні від `-50` до `50` (використовуйте `Random.nextInt(-50, 51)`).  
      *Зверніть увагу:* врахуйте, що випадковий коефіцієнт `a` не має дорівнювати `0` (щоб уникнути падіння конструктора).
    * За допомогою ланцюжка методів колекцій (`filter`, `forEach`):
        1. Залиште тільки ті рівняння, які мають **рівно два розв'язки** (перевірте через `discriminant > 0` або `solve().size == 2`).
        2. Виведіть у консоль кожне з таких рівнянь разом із його знайденими коренями.
    * Виведіть загальну кількість знайдених рівнянь із 2 коренями.
