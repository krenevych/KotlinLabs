### Вхідні дані

### Частина 4. Власна функція вищого порядку (Higher-Order Function)

1. Опишіть функцію-розширення `filterAndTransform` для списку продуктів:

   ```kotlin
   fun List<Product>.filterAndTransform(
       predicate: (Product) -> Boolean,
       transform: (Product) -> String
   ): List<String>
   ```

   **Параметри функції:**
   - `predicate` — функціональний тип `(Product) -> Boolean`, що визначає умову відбору;
   - `transform` — функціональний тип `(Product) -> String`, що задає правило перетворення продукту на текст.

   **Логіка роботи:** функція перебирає поточний список, відбирає елементи, для яких `predicate` повертає `true`, викликає для них `transform` та повертає новий список `List<String>`.

2. Викличте написану функцію для пошуку всіх товарів, ціна яких менша за `300.0`, і згенеруйте для них промо-повідомлення формату:
   ```text
   Акційна ціна на <Назва>: лише $<Ціна>!
   ```
3. Оформіть виклик за допомогою синтаксису **Trailing Lambda** (винесення лямбди `transform` за круглі дужки `{ }`).
